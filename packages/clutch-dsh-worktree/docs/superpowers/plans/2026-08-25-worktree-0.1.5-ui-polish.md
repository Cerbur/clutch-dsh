# Worktree 0.1.5 UI Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (\`- [ ]\`) syntax for tracking.

**Goal:** Remove Worktree branch-context flicker, add complete-value hover cards in both Session presentations, align the Sidebar footer action with native typography, and remove the redundant collapsed WT rail button.

**Architecture:** Keep the existing browser-local WorktreeContextProjection and /api Manager contract. Cache only the latest contract-shaped Worktree view facts per Workspace, gate snapshot-triggered refreshes by current identity, and resolve the active Session from cached facts while a background read runs. Keep hover presentation local to the existing Header/Hero consumers, and keep Sidebar changes inside the plugin's existing slot action and overlay CSS.

**Tech Stack:** TypeScript, React TSX, CSS Modules, DSH Client primitives (HoverCard), Node test runner, pnpm workspace.

## Global Constraints

- Work only in /private/tmp/clutch-dsh-wt-worktree-0.1.5-ui-polish on branch wt-worktree-0.1.5/feat-ui-polish, based on wt-worktree-0.1.5/release.
- Do not modify DSH source, native packages, Host, Manage, Provider, Remote, transport, sidecar schema, or Session content.
- DSH remains the source of truth for Workspace/Session identity and metadata; browser-local context facts remain contract-shaped and in-memory.

- The package version remains 0.1.4; the 0.1.5 target is the release/worktree boundary, not an authorized package version bump or publish operation.
- Use apply_patch for all local source, test, plan, and documentation edits.
- Follow TDD: each production behavior change has a failing regression test observed before implementation and a focused green run afterward.

- [x] **Step 5: Add a browser-local cache and identity helpers.**

The helper shapes are:

~~~ts
const viewCache = new Map<string, WorktreeViewData>();
let lastObservedIdentity: CurrentIdentity | undefined;

const sameIdentity = (
  left: CurrentIdentity | undefined,
  right: CurrentIdentity,
): boolean => left?.sessionId === right.sessionId
  && left?.workspaceId === right.workspaceId;

const workspaceTitleFor = (workspaceId: string): string | undefined =>

  )?.title;
~~~

Keep these facts browser-local. Do not persist the Map or expose it through WorktreeContextState.
