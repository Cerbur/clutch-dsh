> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the plugin's Chinese-only README with an English `README.md` and a matching Chinese `README.zh.md` that document the current Worktree behavior, screenshots, npm-first installation, and detailed usage.

**Architecture:** Keep the public documentation facts in two parallel Markdown documents. Reuse the existing localized screenshots and add a small structural parity test that checks heading shape, screenshot references, and installation order without requiring browser execution.

**Tech Stack:** Markdown, Node.js built-in test runner, Prettier.

## Global Constraints

- `README.md` is English and `README.zh.md` is Chinese; both documents must be updated together.
- The documents must describe the same behavior, data boundaries, limitations, and installation sources.
- The first four public sections are introduction/screenshots, capabilities, installation, and detailed usage.
- npm installation appears before repository checkout and Git source installation.
- Do not copy the current package version into README prose.
- Reuse `assets/screenshots/screenshots-en.png` and `assets/screenshots/screenshots-zh.png`.
- Do not modify source code, package manifest, release version, or root collaboration rules in this worktree.

### Task 1: Add a README structure regression test

**Files:**
- Create: `/Users/yuancheng/Documents/Code/clutch-dsh/packages/clutch-dsh-worktree/test/readme-parity.test.mjs`

**Interfaces:**
- Consumes: `README.md` and `README.zh.md` as UTF-8 text.
- Produces: a test that fails when either README is missing, has a different heading-level structure, omits its localized screenshot, or puts local/source installation before npm installation.

- [ ] **Step 1: Write the failing parity test.**

Create the test with these assertions:

```js
import assert from 'node:assert/strict';
import { readFile } from 'node:fs/promises';
import test from 'node:test';

const readme = await readFile(new URL('../README.md', import.meta.url), 'utf8');
const readmeZh = await readFile(new URL('../README.zh.md', import.meta.url), 'utf8');

function headingShape(source) {
  return [...source.matchAll(/^(#{1,3})\s+/gm)].map(([heading]) => heading.trim().length);
}

function indexOfAny(source, patterns) {
  const indexes = patterns.map((pattern) => source.indexOf(pattern));
  return Math.min(...indexes.filter((index) => index >= 0));
}

test('keeps English and Chinese plugin READMEs structurally aligned', () => {
  assert.deepEqual(headingShape(readme), headingShape(readmeZh));
  assert.match(readme, /assets\/screenshots\/screenshots-en\.png/);
  assert.match(readmeZh, /assets\/screenshots\/screenshots-zh\.png/);

  const npmInstall = indexOfAny(readme, [
    'dsh plugin --profile web add @cerbur/clutch-dsh-worktree',
  ]);
  const repositoryInstall = indexOfAny(readme, [
    'pnpm --filter @cerbur/clutch-dsh-worktree build',
    'github:Cerbur/clutch-dsh#path:/packages/clutch-dsh-worktree',
  ]);
  assert.ok(npmInstall >= 0);
  assert.ok(repositoryInstall > npmInstall);
});
```
