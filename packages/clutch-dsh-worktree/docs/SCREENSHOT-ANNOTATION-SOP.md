# 截图标注 SOP（简版）

日期：2026-11-04
适用：DSH 插件截图、功能对比图、README / Release 配图

一张图只讲一件事。默认只保留 **标题 + 截图 + 1–2 个框/标签**；不加图例、页脚和结论卡片。

## 1. 颜色

只使用三种语义色：

| 颜色 | 色值 | 用途 |
| --- | --- | --- |
| 绿 | `#4ADE80` | 插件能力、快捷筛选、Worktree |
| 蓝 | `#60A5FA` | Session 绑定、执行目录 |
| 黄 | `#FBBF24` | 原生 DSH、风险、未勾选项 |

背景 `#0B0D10`，边框 `#2A3138`，主文字 `#F2F4F6`，次文字 `#A6B0BA`。

## 2. 框与标签

- 框：3px、圆角 12px、**不填充**；只框关键区域。
- 标签：17px W6 短句，放在框右侧或下方，用 2px 同色短线指向框。
- 一张图最多 **2 个框、2 个标签**；优先保留“阅览路径”和“结论”各一个。
- 标签不能遮住 Session 标题、时间、勾选项和主视图右上角的 Worktree 名称。
- 不使用 ①②③ 图例；标签本身写清含义，例如：
  - `快捷筛选`
  - `feat-activity-filter · 2 个会话`
  - `没有 Worktree 层级`
  - `工作目录不可见`

## 3. 单图布局

```text
画布：1398 × 820–920
标题：24,20  34/W6
副标题：24,64  19/W3
截图：24,100（1350 宽；保留主视图标题行）
```

- 截图使用 2× DSH Web 图，不放大。
- 标题讲结论；副标题一行讲范围或限制。
- 不加页脚；数据来源写在 README 或正文，不写在图上。

## 5. 取坐标

```js
[...document.querySelectorAll('[data-worktree-motion-key^="group:worktree:"]')]
  .map((e) => ({ key: e.getAttribute('data-worktree-motion-key'), rect: e.getBoundingClientRect().toJSON() }));
```

- 截图是 2×：标注坐标 = `rect * 2`。
- 先 `scrollTop = 0`，截图后立即取 rect，不复用旧坐标。
- 框四周留 4–8px；标签放在框外，不压 UI。
