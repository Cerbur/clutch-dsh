# Fireworks 0.2.0：B 站推广视频拍摄稿

定位：面向正在使用或关注 DeepSeek Harness（DSH）的开发者，展示完成任务的仪式感、后台会话提醒和动画自定义。建议横屏 16:9、约 3 分 30 秒，录屏加后期配音，无需出镜。时间轴为剪辑参考，以实际口播速度调整。

一句话主张：**让 Agent 完成重要任务后，给你放一场烟花。**

本稿依据当前 `package.json` 的 0.2.0、双语 README 和动画设置计划编写。录制前确认实际安装版本；仓库现有设置截图仍显示旧版本号，应重新录制实际页面。

## 一、先准备这些内容

| 素材             | 准备内容                                                                 | 用途                           |
| ---------------- | ------------------------------------------------------------------------ | ------------------------------ |
| DSH 演示环境     | DSH 0.2.1-rc.1 或更高、Fireworks 0.2.0、已启用插件的 Web UI              | 真实操作主画面                 |
| 一个真实的小任务 | 独立演示项目里的小 Bug 或功能，有可以运行的验证命令                      | 展示完成任务 → 调用工具 → 庆祝 |
| 两个会话         | A 命名为「修复空标题提交」，B 命名为「下一个任务」；名称可按实际项目更改 | 展示后台完成及返回来源         |
| 三个内置效果     | Emoji 礼花、鲸跃烟火、极光光环                                           | 开场和模板展示                 |
| 一个自定义动画   | 用设置页提供的提示词提前生成、保存为 `.js` 并完整预览通过                | AI 自定义演示                  |
| 安装终端         | 使用干净终端，放大字体                                                   | 展示两行安装命令               |
| 项目页面         | 打开 GitHub 中 Fireworks 的 README                                       | 结尾获取入口                   |

建议录屏 1920×1080、60 fps；机器有压力时优先保证真实播放流畅。放大 UI 到观众能读清 toast 和卡片文字的程度。关掉无关桌面通知，隐藏密钥、私人路径和私人会话标题。

先确认系统未开启“减少动态效果”，否则按产品设计只显示静态中点帧。先在深色主题试录鲸鱼，检查压缩后的蓝色轮廓是否清楚，再决定主视频主题；浅色效果另录一条。

## 二、完整分镜与逐字台词

### 01｜00:00–00:12｜先给观众看结果

**画面**

直接从真实任务完成后的庆祝开始。前 5 秒保留一整段鲸跃烟火：发射、爆炸、鲸鱼、喷泉、淡出。画面里尽量同时看清完成消息和 toast。后半段切 Emoji 与极光各一小段。

**台词**

> 如果 AI 帮你修完一个 Bug，除了说“完成了”，还能给你放一场烟花呢？这只鲸鱼，就是我给 DeepSeek Harness 做的插件。

**字幕/剪辑**

第一屏大字：「Bug 修好了，值得放个烟花。」角落小字：「Fireworks 0.2.0 · DSH 插件」。不要先放 Logo 动画或个人介绍。

开场鲸鱼如果来自设置页预览，标注“动画预览”，不要把它剪成任务完成触发的证据。优先使用真实工具触发素材。

### 02｜00:12–00:30｜用一句话讲清是什么

**画面**

会话里的任务结果 → `happy_fireworks` 工具调用 → 插件详情页的名字与图标。放大名称时保留周边 UI，帮助观众理解这是插件。

**台词**

> 它叫 Fireworks，是给 DSH Web 界面加的一个庆祝插件。Agent 完成重要里程碑后，可以调用 happy fireworks，放一小段动画，再带上一句完成消息。零点二版本，还能换动画，做自己的效果。

**字幕/剪辑**

口播读“happy fireworks”，字幕和工具画面写准确标识 `happy_fireworks`。介绍 DSH 时加小字「DeepSeek Harness / DSH」，避免让观众误认成 DeepSeek 官网聊天功能。

### 03｜00:30–01:00｜真实完成一个任务

**画面**

展示事先准备的小 Bug：空标题点击提交仍然通过。切入给 Agent 的任务，压缩等待与代码输出，保留修复摘要、实际测试结果以及随后出现的礼花。

如果实际演示不是这个 Bug，把画面、会话名、提示词和下面台词中的任务一起替换。

**台词**

> 比如这里，表单的空标题没有拦住。我让 Agent 修复，再跑相关测试。中间的过程我们快进一下。修复完成、验证通过，它再调用庆祝工具。这样，一个任务的收尾，就有了一个看得见的完成瞬间。

**字幕/剪辑**

任务过程加「已加速」。测试结果和工具调用停留到能读清，不要用动画代替验证结果。若实际测试失败，不剪出“验证通过”的结论。

### 04｜01:00–01:30｜后台会话也能提醒

**画面**

单独录一条连续素材：在 A 会话提交任务 → 任务运行时切到 B 会话或插件页 → 等 A 完成 → 当前页面出现礼花与 toast → 点击 `Open session →` → 回到 A 的完成结果。

优先保持“切走—出现通知—点击返回”连续；若等待很长，可在等待段明确标注加速，通知出现后恢复正常速度。

**台词**

> 更实用的是，你不用一直守着这个会话。我先切去看别的内容，原来的任务继续跑。等它完成并调用工具，当前这个 DSH 窗口里照样会出现礼花和通知。点一下 Open session，就能回到完成任务的那个会话，多开几个任务时也方便认。

**字幕/剪辑**

依次显示：「切走，任务继续」「后台完成」「点击返回来源会话」。保留可见鼠标点击与返回结果。这里的后台指 DSH 内的非当前会话，不演示切到别的应用也有桌面烟花。

### 05｜01:30–01:55｜展示三种内置效果

**画面**

打开「插件 → @cerbur/clutch-dsh-fireworks → 烟花动画」。依次预览 Emoji、鲸鱼、极光，再点击自己喜欢的卡片，拍到「当前使用」状态变化。

鲸鱼在开头已经完整展示，这里可以用短片段；其他效果尽量给足能辨认风格的时间。

**台词**

> 内置有三种效果：Emoji 礼花、鲸跃烟火，还有极光光环。默认是五秒的鲸鱼烟花，每次都会出现鲸鱼。点预览可以先看，点卡片才是切换，立即生效，不用再找保存按钮。

**字幕/剪辑**

强调：「预览 ≠ 切换」「点击卡片，立即生效」。只有工具触发的真实庆祝有任务 toast，预览不会创建 toast。

### 06｜01:55–02:35｜把自己的创意变成庆祝动画

**画面**

展开「用 AI 生成自己的动画」→ 复制提示词 → 粘贴到自己常用的 AI 工具 → 替换末尾创意描述 → 展示生成的 `.js` 文件 → 回到 DSH 点击「导入 js 动画」→ 选择文件 → 导入确认弹窗 → 预览完整效果 → 点击「确认添加」→ 新卡片显示「当前使用」。

生成过程可以加速；保留足够时间展示自定义成品。确认按钮一定在完整预览之后点击。录制用的生成结果提前试过，但镜头中的操作应保持真实。

**台词**

> 这次我最想展示的，是自己做动画。这里已经准备好了生成提示词，复制给你常用的 AI，再把最后的创意换成自己的。比如：“一颗金色种子，长成一棵会发光的树。”把生成的 JS 文件导回来，先预览，满意了再确认添加，它就会成为之后的庆祝效果。不一定一次就满意，继续改创意、重新生成就行。

**字幕/剪辑**

用四个短字幕带路：「复制提示词 → 描述创意 → 导入 JS → 预览并确认」。角落小字：「AI 生成在你使用的工具中完成」。不要做成插件自带模型、点击即可直接生成的效果。

如果最终生成的不是树，把创意台词、文件名、预览和字幕一起换成真实结果。示例脚本 `assets/animations/example-custom.js` 可以作为备用的“自定义脚本导入”素材，但不能把它说成这次 AI 现场生成的结果。

### 07｜02:35–02:50｜展示轻量、不挡操作

**画面**

一条浅色主题、一条深色主题的效果；在动画播放时点击正常 UI 或切换 DSH 页面，展示底层仍能操作。可以用一次真实庆祝录到“关闭 toast 后动画继续”。

**台词**

> 动画是透明叠在界面上的，底下还能继续操作，浅色深色都能用。它适合重要任务的收尾；读取文件、查一次状态，就没必要每一步都庆祝了。

**字幕/剪辑**

「透明覆盖 · 不拦截底层操作」。不要宣传“完全不占性能”或“所有机器都保证 60 帧”。

### 08｜02:50–03:15｜给观众可执行的安装方式

**画面**

终端清晰展示下面两行命令，切到实际 DSH 插件详情页，确保版本显示 0.2.0。再闪回 `happy_fireworks` 工具调用位置。

```bash
dsh plugin --profile web add @cerbur/clutch-dsh-fireworks
dsh web
```

**台词**

> 想试的话，先准备好 DSH CLI，宿主需要零点二点一 RC 一或更高版本。用这条命令安装插件，再启动 DSH Web。安装后会给 Agent 里程碑庆祝的使用指引，你也可以直接说：“调用 happy fireworks，放个烟花。”项目地址和命令，我都放在简介里。

**字幕/剪辑**

区分「Fireworks 0.2.0」与「DSH ≥ 0.2.1-rc.1」。源码 checkout 用户可使用等价 `pnpm dsh`，这个细节放简介，不占主片时间。

安装命令不锁定版本，获取的是 npm 当前可用版本；录制时核对插件详情页。若需要固定复现 0.2.0，先按宿主支持的版本指定方式配置，不把未来的最新版页面冒充成 0.2.0。

### 09｜03:15–03:30｜用创意问题收尾

**画面**

自定义效果最漂亮的片段 → 鲸鱼定格或项目页面。结尾放插件名字和「项目地址见简介」，为结束卡留约两秒。

**台词**

> Fireworks 零点二，让 Agent 的“做完了”，变成一场小小的庆祝。如果是你，会给任务完成设计什么动画？在评论区留个脑洞。喜欢这个插件，也欢迎去 GitHub 点个 Star。

**字幕/剪辑**

最后一屏：「你的任务完成动画，会是什么？」不在末尾叠加过多关注、投币、收藏口令。

## 三、录制时可以直接使用的提示词

### 真实任务演示

仅在自己准备好的、确实存在该问题的独立演示项目中使用：

```text
修复这个演示项目中“空标题仍然可以提交”的问题。
先确认问题原因，完成修复，并运行与改动相关的测试。
不要提交、推送或发布。
只有修复完成且相关验证通过后，才调用 happy_fireworks，
message 使用“空标题校验已修复，测试通过！”；验证未通过就说明问题，不要庆祝。
最后简要总结修复内容和验证结果。
```

开始任务后立即切到另一个 DSH 会话或插件页。优先挑选耗时足够完成切换的小任务，提前试录一次。上述演示明确要求了工具调用，画面字幕写「任务完成后调用庆祝工具」，不宣称 Agent 在所有任务里都必定自动调用。

### 没有现成 Bug 时的替代任务

```text
阅读这个演示项目的 README 和主要入口文件，
为“增加空标题校验”写一份可执行的实施计划，列出改动位置、边界情况和验证步骤。
只输出计划，不修改文件，不提交、推送或发布。
完成这份计划后，调用 happy_fireworks，message 使用“实施计划已完成！”
```

如果使用替代任务，主片第 03 段台词改为：

> 比如，我让 Agent 先为一个功能写实施计划，列清楚要改哪里、有哪些边界情况、怎么验证。中间过程快进一下。计划完成后，它调用庆祝工具，给这一个阶段画个句号。

### 只补录特效时

```text
这是一次动画录屏测试。请调用 happy_fireworks，
message 使用“Fireworks 0.2.0，开场！”
```

补录素材用来展示特效外观；若镜头描述触发来源，标注手动测试，不说成真实修复完成。

### AI 动画的创意描述

先复制设置页完整提示词，只替换末尾创意部分，不要丢弃原有接口与性能要求：

```text
动画名：金色生长。
一颗金色种子从画面下方升起，在中央停顿，展开成一棵有清晰树冠的发光树。
树枝逐层长出，少量星点像果实一样点亮，最后树冠散成柔和光点并平滑消失。
总时长 5 秒。保持透明背景，不绘制整幕底色，不使用文字、外部图片或音频。
主体需要在深浅主题下都清楚，周围留白，让用户仍能看到背后的 DSH 页面。
按上面的完整脚本规范输出可直接导入的独立 .js 文件。
```

AI 输出需通过导入校验并完整预览。失败时修正脚本或重新生成，成片不承诺“一次生成必定可用”。

## 四、按这个顺序录，剪辑更省事

1. **先录成品效果**：真实工具触发鲸鱼两条，各保留完整 5 秒；Emoji、极光各一条；浅色与深色各留一条。
2. **录主故事**：问题复现、任务输入、完成摘要与测试结果；再录一条完整的后台会话通知与点击返回链路。
3. **录设置操作**：插件入口、三张卡片、预览、选择后的「当前使用」状态。
4. **录自定义流程**：复制提示词、AI 创意输入、生成结果文件、导入确认、完整预览、确认添加。保留最终采用的脚本文件，方便补录。
5. **录安装与结尾**：命令、实际版本、GitHub 页面。
6. **最后配音**：按分镜单独录九段，每段出入各留约一秒。先粗剪画面，再按口播长度调整节奏。

素材可命名为 `01-whale-real`、`02-task-result`、`03-background-return`、`04-presets`、`05-ai-import`、`06-themes`、`07-install`。录屏文件留在本地素材目录，不加入源码 Git。

音乐选轻快但不抢人声的可用素材，烟花高点可以加轻微音效；音效属于后期制作，别让观众以为插件自带声音。点击与关键状态变化各留短暂停顿，尽量不对小字界面做快速摇移。

## 六、拍完检查

- 插件详情是实际安装的 0.2.0；没有把现有截图的旧版本号带入成片。
- 开头至少给了一次完整鲸跃烟火；鲸鱼是默认效果，每次完整播放都会出现，不说成随机彩蛋。
- 后台任务、通知、点击返回之间的因果能看清，没有把设置页预览当成任务通知。
- 预览不会切换当前动画，也不创建 toast；导入是在「确认添加」后保存启用。
- AI 生成过程在外部工具完成；创意台词与实际导入成品一致。
- 成片只承诺 DSH 窗口内的效果，不承诺系统桌面通知、必定自动调用或性能提升。
- 安装命令、package 名称、宿主要求与 README 一致。
- 字幕、人声、UI 文字在手机端全屏观看时能读清。
